# آزمایشگاه تعاملی فیزیک دوازدهم (رشته علوم تجربی — ویژه کنکور)

این برنامه بر اساس کتاب درسی **فیزیک (۳) پایه دوازدهم رشته علوم تجربی (`C112244.pdf`)** طراحی شده است و تمام **۴ فصل و ۲۱ زیربخش** کتاب را به صورت کاملاً مجزا، بصری و تعاملی پوشش می‌دهد.

## اجرای برنامه

در ترمینال داخل پوشه `phys12-lab` دستور زیر را اجرا کنید:

```bash
npm install
npm run dev
```

سپس آدرس نمایش داده شده در ترمینال (معمولاً `http://localhost:5174`) را در مرورگر باز کنید.

## ساختار آموزشی هر زیربخش

1. **آزمایشگاه تعاملی و فرمول زنده**: بازی با متغیرها، مشاهده فوری حرکت‌ها، نمودارهای مکان/سرعت/شتاب، نیروها، نوسان و امواج، شکست نور، اتم بور و واپاشی هسته‌ای همراه با جایگذاری عددی زنده و راهنمای تک‌تک نمادها.
2. **درسنامه فشرده و نکات کنکوری**: خلاصه دقیق مطابق صفحات کتاب درسی، جدول متغیرها و یکاها، نکات طلایی کنکور و تله‌های رایج طراحان.
3. **بانک تمرین، تست کنکوری و مولّد تمرین نامحدود**: تست‌های ۴ گزینه‌ای و مسائل عددی با راهنمایی و پاسخ تشریحی مرحله‌به‌مرحله + تولید تمرین تصادفی نامحدود.
